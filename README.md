# 禅道个人 IPD Windows 整合安装包

包含禅道开源版 22.6 完整源码，以及已合入的阶段管理、交付物清单、技术组和每阶段会议资料功能。

**[下载安装包（约 58 MiB）](https://github.com/zhengfeifei987-web/-/raw/refs/heads/main/ZentaoIPD-Setup-v1.0.0.zip)**

这是首次联网准备运行环境的整合安装包。Windows 运行库没有预装在 ZIP 内；首次运行会自动从官方渠道下载并校验。准备完成后，核心功能可在本机离线使用。

## Windows 10/11 64 位使用步骤

1. 下载 ZIP 并完整解压，建议放在 `C:\ZentaoIPD`。
2. 双击“首次安装并启动.cmd”，保持网络连接。若微软运行库需要安装，按 Windows 提示确认。
3. 浏览器打开后完成禅道本地安装，设置自己的管理员账号和密码。
4. 登录后打开“个人IPD”，点击启用，选中自己的项目并初始化阶段。
5. 以后使用“启动.cmd”和“停止.cmd”。

详细操作说明在 ZIP 内的“使用说明.txt”。

## 包含功能

- 六阶段：概念、计划、开发、验证、发布、生命周期，可调整名称及期限。
- 交付物清单：负责技术组、必交标记、状态、日期、说明和附件。
- 技术组：默认机械、硬件、软件、测试、综合，可自行维护。
- 每阶段会议：主题、时间、相关技术组、附件、会议纪要、评审结论、后续待办。
- 阶段门槛：必交项未完成不能结束阶段，完成后交付物只读，会议资料仍可补充。

## 验证范围

IPD 功能在 Linux 测试环境的禅道 22.6 / 22.7 上通过功能和权限检查。自动安装器通过语法、校验和解压安全检查，但尚未在真实 Windows 电脑上实跑。

程序仅监听本机地址，面向个人单机使用。安装包不包含云实例账号、密码、数据库或用户附件。高级 Blocksuite 文档与白板资源未包含在本次公开源码中。

基础项目来源：https://github.com/easysoft/zentaopms 。原项目及运行组件的许可证随包保留，不包含商业 IPD 版代码。

安装包 SHA256 见同目录的 `.sha256` 文件。
